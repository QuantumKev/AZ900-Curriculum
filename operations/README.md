# Cohort operations

Phase 5. Enrollment messages, a readiness tracker, and exam-scheduling support.
Nothing here sets a calendar date. Fill `[meeting time]` and `[room or link]` when you
send a message.

| File | Use it for |
| --- | --- |
| [enrollment-communications.md](enrollment-communications.md) | Messages you can send as written: welcome, after Session 1, before each session, after a checkpoint, missed session, exam window |
| [readiness-tracker.csv](readiness-tracker.csv) | One row per learner. Quiz percents, checkpoint percents, practice-assessment scores, exam date status |
| [readiness-tracker.md](readiness-tracker.md) | What each column means, the readiness bar, and what to do when someone is behind |
| [exam-scheduling.md](exam-scheduling.md) | How a learner schedules AZ-900, what to say in Session 12, accommodations, retakes |
| [session-log.md](session-log.md) | What this cohort actually did, starting with Session 1 |

The readiness bar is the one already set in the course overview: 85% or better overall,
no domain below 75%, on the Session 12 set and on a separate official practice
assessment, with no objective left blank on the checklist.
