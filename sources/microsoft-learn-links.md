## Official learning paths

The official course is delivered as a four-part "Introduction to Cloud Infrastructure"
series. Parts 1–3 carry the exam content; part 4 is hands-on projects.

| Part | Learning path | Modules |
| --- | --- | --- |
| 1 | [Describe cloud concepts](https://learn.microsoft.com/en-us/training/paths/microsoft-azure-fundamentals-describe-cloud-concepts/) | 3 |
| 2 | [Describe Azure architecture and services](https://learn.microsoft.com/en-us/training/paths/azure-fundamentals-describe-azure-architecture-services/) | 5 |
| 3 | [Describe Azure management and governance](https://learn.microsoft.com/en-us/training/paths/describe-azure-management-governance/) | 4 |
| 4 | [Apply Azure skills in guided projects](https://learn.microsoft.com/en-us/training/paths/introduction-cloud-infrastructure-apply-azure-skills-guided-projects/) | 8 |

The learning paths and the official course were both renamed to "Introduction to Cloud
Infrastructure." Older material — including both secondary references — calls these
"Microsoft Azure Fundamentals" paths. The URLs are unchanged, so old links still resolve.

## Sources deliberately not used

- Exam dumps, brain dumps, and "real exam questions" sites — prohibited by the Microsoft Certification Exam Candidate Agreement and excluded from this curriculum entirely.
- Third-party practice tests of unknown provenance. The only practice instrument referenced is Microsoft's official free practice assessment.
- Link shorteners and redirect services for Microsoft resources. Canonical `learn.microsoft.com` URLs are used so learners can see where a link goes. The one exception is `aka.ms/examdemo`, which is Microsoft's own shortener and the only published entry point to the exam sandbox.
