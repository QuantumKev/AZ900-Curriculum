## Course description

This course takes you from no cloud background to ready to sit Exam AZ-900, Microsoft Azure
Fundamentals, in six weeks. You will learn what cloud computing is and how it changes who
is responsible for what; how Azure is organized into regions, subscriptions, and resource
groups; what Azure's core compute, networking, storage, and identity services do and when
to choose each one; and how organizations control cost, enforce governance, deploy
resources, and monitor what they have built.

Every topic in this course maps to an objective Microsoft publishes for the exam. The
course covers all 57 of them, weighted to match the exam itself.

You do not need prior IT experience. Sessions 1 and 2 build the vocabulary that the rest of
the course depends on.

## What you will be able to do

By the final session you will be able to:

1. Explain cloud computing, the shared responsibility model, cloud deployment models, and cloud service types, and pick the right model for a described situation.
2. Describe how Azure is organized physically and administratively, and place any resource correctly in the management group, subscription, resource group, and resource hierarchy.
3. Compare Azure compute, networking, and storage options and select a reasonable service for a stated requirement.
4. Describe Azure identity, access, and security features including Microsoft Entra ID, multifactor and passwordless authentication, Conditional Access, role-based access control, Zero Trust, defense in depth, and Microsoft Defender for Cloud.
5. Describe how Azure costs arise, estimate them with the pricing calculator, and describe Azure's governance, deployment, and monitoring tools.
6. Answer AZ-900-style questions across all three exam domains at a level that supports passing the exam.

## What the exam covers

The exam has three domains. Class time is allocated to match their weights.

| Domain | Share of exam | Sessions |
| --- | --- | --- |
| Describe cloud concepts | 25–30% | 1–2, revisited throughout |
| Describe Azure architecture and services | 35–40% | 3–7 |
| Describe Azure management and governance | 30–35% | 8–11 |

Exam facts worth knowing on day one:

- **45 minutes** of exam time, within a **65-minute** appointment.
- A score of **700 or greater** passes. The score is not a simple percentage of questions.
- The exam is **proctored**, in a test center or online.
- You **cannot** look things up on Microsoft Learn during a Fundamentals exam. That feature exists only for the more advanced role-based exams, and learners are often surprised by this.
- If you do not pass, you may retake after **24 hours**. Later retakes have longer waits.
- This certification **does not expire**.

## How assessment works

Nothing in this course is designed to sort or rank you. Every quiz exists to show you and
your instructor which exam objectives are solid and which need another pass, while there is
still time to fix them.

| What | When | Length | Graded? |
| --- | --- | --- | --- |
| Warm-up recall questions | Start of every session after the first | 10 min, 6 questions | No |
| Session quiz | End of every session | 10–15 min, 10–12 questions | Yes, for feedback |
| Domain 1 checkpoint | Start of Session 3 | 15 min, 12 questions | Yes, for feedback |
| Domain 2 checkpoint | Start of Session 8 | 15 min, 12 questions | Yes, for feedback |
| Domain 3 checkpoint | Inside the Session 11 quiz | 15 min, 12 questions | Yes, for feedback |
| Final readiness practice | Session 12, timed | 45 min, 45 questions | Yes, for feedback |
| Microsoft's official practice assessment | Session 11 homework, then during the 10-day window | 45 min | Not collected |

Question styles match the exam: single best answer, select-all-that-apply, matching, and
yes/no statement sets. Every question is reviewed in class right after the quiz, and every
one is tied to a published exam objective so you can look up exactly what to study.

### Readiness bar before you book the exam

You are ready when **all three** of these are true:

1. 85% or better on the Session 12 final readiness practice, with no single domain below 75%.
2. 85% or better on a separate attempt at Microsoft's official practice assessment, again with no domain below 75%.
3. No objective left marked "blank" on your objective checklist.

The bar sits above the actual passing score on purpose. Practice scores and exam scores are
not the same measure, and Microsoft does not publish a relationship between them.

## What you need to do

### Before Session 1

1. **Create a free Microsoft Learn account** at [learn.microsoft.com](https://learn.microsoft.com). Use a personal Microsoft account rather than a work or school account. This matters later: if you register for the exam with a work account and then leave that organization, your certification records can be lost and cannot be recovered.
   - This account is free, gives you every training module used in this course, and gives you the official practice assessment.
2. **Decide how you will do hands-on work.** Any one of these is fine:
   - Create your own [Azure free account](https://azure.microsoft.com/en-us/free/). Check the current offer terms on that page — what is included changes from time to time. A credit card is used for identity verification; you are not charged unless you choose to upgrade. Students should check whether the **Azure free student account** applies to them, which needs no credit card.
   - Use a subscription your organization or instructor provides.
   - Use the no-cost path. Every session has an alternative activity that needs no Azure subscription, using Microsoft Learn's guided projects, the pricing calculator, and instructor demonstrations. **You can complete and pass this course without ever creating an Azure account.**
3. **Bring a device** that can open a browser: laptop preferred, tablet or phone workable.

### Every week

- **Attend both sessions.** The warm-up at the start and the quiz review at the end are where most of the learning happens, and neither can be caught up by reading slides.
- **Complete the assigned Microsoft Learn module** before the next session — roughly 45–60 minutes. Each module ends with a short knowledge check; do it.
- **Delete any Azure resources you created in class** at the end of each session if you are using your own subscription. You will learn how in Session 3. This is a real cloud skill, not just housekeeping.
- **Keep your objective checklist current.** You will get a list of all 57 exam objectives. After each quiz review, mark each one you touched: confident, shaky, or blank. Bring it to every session; Sessions 11 and 12 are built around it.

### After the final session — your 10-day plan

You will get this as a handout in Session 12. The short version:

| Day | Focus |
| --- | --- |
| 1 | Review your Session 12 debrief and **book your exam** for day 8, 9, or 10 |
| 2 | Cloud concepts |
| 3 | Azure architecture and compute |
| 4 | Networking and storage |
| 5 | Identity and security |
| 6 | Cost, governance, management, and monitoring |
| 7 | Full official practice assessment, timed; review every miss |
| 8 | Repair only the objectives you missed on day 7 |
| 9 | Second full practice assessment; confirm the readiness bar; walk the exam sandbox again |
| 10 | Sit the exam. Light review only — no new material |

Booking the exam on day 1 is the single most important step. Learners who leave the booking
until they "feel ready" tend never to book at all.

### A note on study materials you find online

You will find many free AZ-900 guides, videos, and question sets. Two things to know:

- **Microsoft's own documentation is the authority.** Where any other source disagrees with Microsoft Learn, Microsoft Learn is right. Third-party material also goes stale — the exam was last updated in July 2026, and much of what is online predates that. Expect to see retired product names such as "Azure Active Directory" (now Microsoft Entra ID) and tools that no longer exist, such as the Total Cost of Ownership calculator.
- **Do not use exam dumps.** Sites offering "real exam questions" violate the agreement you accept when you register for the exam, and can cost you your certification. They also do not work: the exam tests whether you can pick the right service for a situation, which memorized answers do not teach you. Everything you need is free and legitimate, and this course points you at all of it.

## Policies

**Attendance.** Attend all 12 sessions. If you miss one, get the session's objective list and
the quiz with its answer key from your instructor, complete the Microsoft Learn module for
that session, and take the quiz on your own before the next session. Tell your instructor
which objectives felt shaky so they can fold them into a warm-up.

**Participation.** The sorting, matching, and estimating activities work only if you commit
to an answer and defend it. Being wrong out loud in Session 2 is much cheaper than being
wrong on the exam in Week 7.

**Quizzes.** Open-book is fine for warm-ups and session quizzes if your instructor allows
it, but it defeats the purpose — the point is to find out what you can recall unaided. The
Session 12 final practice is closed-book and timed, because the exam is.

**Late work.** The Microsoft Learn modules are not graded, but skipping them compounds
quickly. Each session assumes the previous module is done.

**Academic honesty.** Do your own quizzes. Do not share questions or answers outside the
class, and do not bring exam dump material into the course.

**Accessibility and accommodations.** Tell your instructor what you need and it will be
arranged — every activity in this course has a keyboard-only path, and diagrams have text
equivalents. For the exam itself, Microsoft offers accommodations including extra time and
assistive technology support, but **you must request them before you register**. Start at
[Request accommodations](https://learn.microsoft.com/en-us/credentials/certifications/request-accommodations), and ask your instructor in Session 1 if you plan to request anything, so there is time.

**Cost safety.** If you use your own Azure subscription, you are responsible for what you
create. Delete class resources at the end of each session, and set a budget alert once
Session 8 teaches you how. Use the no-cost path if you would rather not manage this.

## Frequently asked questions

**Do I need IT experience?** No. Microsoft's own audience description assumes some, but this
course does not. Sessions 1 and 2 build the vocabulary from scratch.

**Do I need to know how to code?** No. Nothing in this course or the exam requires coding.
You will see a few command-line commands and a template file, and both are explained.

**Do I have to create an Azure account?** No. Hands-on work is strongly encouraged because
it makes the concepts stick, but every session has a no-cost alternative.

**Will this course make me an Azure administrator?** No, and that is by design. AZ-900 is a
foundational certification that proves you can describe Azure's services and features. It is
the normal first step toward role-based certifications such as Azure Administrator.

**Is AZ-900 required before other Azure certifications?** No. It is not a prerequisite for
anything. It is a common starting point because it makes the later material much easier.

**What if I fail the exam?** You can retake it 24 hours later, with longer waits for
subsequent attempts. Your score report shows performance by domain, which tells you exactly
where to study. Bring it to your instructor.

**How much study time outside class should I plan?** Roughly 1–2 hours per week during the
course for the assigned module and review, then 1–2 hours a day during the 10-day window
after it.
